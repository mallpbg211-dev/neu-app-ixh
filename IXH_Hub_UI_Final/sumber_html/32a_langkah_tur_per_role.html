Pedoman Penulisan & Posisi Tooltip

  • Judul maksimal 3 kata; isi maksimal 2 kalimat (sekitar 120 karakter) dan memakai bahasa sehari-hari.
  • Urutan: kartu ringkasan, tombol aksi, notifikasi, navigasi, lalu tombol akun sebagai penutup.
  • Tooltip tampil di bawah elemen; bila elemen ada di bagian bawah layar (bilah navigasi), tooltip tampil di atas. Panah selalu menunjuk elemen.
  • Tombol: Kembali (tidak ada di langkah 1), Lanjut, Selesai (langkah terakhir), dan Lewati. Indikator titik menunjukkan posisi langkah.
  • Jika elemen tidak tersedia (role tidak punya fiturnya), langkah dilewati otomatis dan jumlah langkah menyesuaikan.
  • Semua teks berasal dari satu berkas string per role sehingga mudah diubah tanpa mengubah layar.

Aturan Bisnis

  • Jumlah langkah: Admin 6, Pengurus 6, Siswa 5. Kartu Saldo Kas hanya ada di tur Admin; tombol Ambil Absensi hanya di tur Admin dan Pengurus.
  • Teks di tabel adalah sumber tunggal isi tooltip untuk implementasi.

  • Layar lain (Absensi, Kas, Jadwal, Tugas) punya petunjuk pertama kali sendiri (32B).
  • Kondisi khusus (Lewati, tur terhenti, TalkBack, tema Liquid Glass) ada di 32D.
