Aturan Bisnis

  • Login pertama dengan password sementara dari Admin wajib ganti password; layar ini tidak bisa dilewati.
  • Password tersembunyi: mata blob terbuka. Tombol mata ditekan (terlihat): mata blob menutup. Syarat: min. 8 karakter, huruf besar, angka, simbol.
  • Persetujuan pesan WhatsApp wajib (aturan kelas yang disepakati wali kelas dan orang tua); tidak ada tombol lewati.
  • Jabat tangan: siswa mengirim satu pesan berbahasa biasa ke bot: “tagihan kas saya”, “laporan kas saya”, “tagihan kas aku”, atau “laporan kas aku”. Bot mengenali kata kas + saya/aku (tidak peka huruf), bukan kata kaku seperti HALO.
  • Pesan harus dikirim dari nomor yang terdaftar; bot hanya membalas tagihan dan laporan kas milik pengirim.
  • Balasan bot berisi data nyata, jadi pesan pertama langsung berguna. Percakapan dua arah juga mengurangi risiko nomor bot diblokir.
  • Saat pesan diterima, status nomor otomatis Valid (menggantikan tes kirim manual untuk siswa baru). Jika gagal, tersedia Hubungi Admin.
  • Kalimat yang sama bisa dipakai kapan saja untuk cek tagihan. STOP tetap ada; status Berhenti memberi tanda ke bendahara untuk menagih langsung (lihat 23).
  • 3 layar pengenalan boleh dilewati; selesai masuk ke Dashboard sesuai role. Password hanya bisa direset Admin lewat Kelola Pengguna.
